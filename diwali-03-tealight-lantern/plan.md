# Diwali 03 — Star Lantern (PSOne Labs)

**Chosen:** name **Star Lantern** ("tea-light holder" in the caption), look **F — Glow Night**. Script: waiting for the client.

3D-printed tea-light lantern: chocolate-brown star-lattice (asanoha / jaali) shade on a terracotta base; an LED tea light
inside throws a star pattern. Footage: VID-20261026-WA0001.mp4(44s, 478x850) + three hand-held photos.

Rules from the client: use the whole clip full screen, keep animation and pattern minimal so it looks real, voice-only
export (music added on Instagram), simple natural words, no logo block at the end.

## Name ideas

| Name | Why |
|---|---|
| **Jaali Lantern** (recommended) | "Jaali" is the Indian word for lattice work; short, easy, instantly understood |
| Sitara Lantern | "Sitara" = star, after the star pattern it casts |
| Taara Tea-light Lantern | "Taara" = star; playful, easy to say |
| Roshni Jaali Lamp | "Roshni" = light; sounds festive |
| Noor Lantern | "Noor" = glow; elegant, one word |
| Jharokha Lantern | after the carved jharokha windows the pattern recalls |
| Chandni Lantern | "Chandni" = moonlight; soft and pretty |
| Jugnu Lamp | "Jugnu" = firefly; cute, memorable |
| Deepika Lantern | from "deep" (lamp); classic Diwali feel |
| Tara Jaal | "star net": the lattice of stars |
| Prakash Pot | "Prakash" = light; earthy, fits the terracotta base |
| GlowJaal | modern, Insta-friendly mix of glow + jaal |
| Starlight Votive | English option, premium sounding |

## Edit (same cut for every look; ~30s, the clip stays full screen and real)

| Time | Clip (WA0001) | Speed |
|---|---|---|
| 0–4 | Shade on the printer bed, picked up and turned (0–7s) | 1.75x |
| 4–7 | Printed base shown (8–13s) | 1.7x |
| 7–12 | Tea light switched on and placed in the terracotta base (14–23s) | 1.8x |
| 12–17 | Shade lowered on, star pattern lights up (24–30s) | 1.2x |
| 17–20 | Lit lantern on the bed (30–36s) | 2x |
| 20–30 | Room lights off: lantern glowing in the dark (36–44s) | 0.8x (slow) |

Straight cuts throughout; one soft fade only at the lights-off moment. Text sits top/bottom, never over the lantern.
